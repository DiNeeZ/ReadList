# 📚 To Read List

Небольшое веб-приложение для поиска книг и ведения своего списка «к прочтению».

## ✨ Что умеет

- 🔍 **Поиск книг** по названию или автору через [Open Library API](https://openlibrary.org/developers/api). Поиск начинается после ввода 3 символов, а новые результаты подгружаются при прокрутке.
- 📖 **Карточка книги**: название, автор и другие подробности о выбранной книге.
- ➕ **Список «To Read...»**: книгу можно добавить в свой список одной кнопкой.
- ✅ **Отметка «прочитано»** и удаление книги из списка.
- 💾 **Сохранение**: список хранится в `localStorage` браузера и не пропадает после перезагрузки страницы.

## 🛠 Технологии

HTML · SCSS · JavaScript (ES-модули) · [Vite](https://vite.dev/)

## 🚀 Запуск

Нужен установленный [Node.js](https://nodejs.org/) (версия 20.19+ или 22.12+).

**1. Установите зависимости** (Vite и Sass поставятся автоматически)

```bash
npm install
```

**2. Запустите проект**

```bash
npm start
```

Откройте в браузере **http://localhost:5173**. Страница обновляется сама, когда вы сохраняете изменения в файлах.

**Сборка для публикации**

```bash
npm run build     # готовые файлы появятся в папке dist/
npm run preview   # посмотреть собранную версию локально
```
